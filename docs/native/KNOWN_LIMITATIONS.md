# Известные ограничения (честный список, после N11)

* **Анимация:** клипы игры декодируются и воспроизводятся (все 2 034 клипа Делсина), но граф анимаций игры
  (`ANIMATION_RUN`, `STRAFE_LAUNCH`, `STRAFE_LANDING`, …) не восстановлен: переходы Idle/Walk/Run/Jump/Fall/Land —
  собственная машина состояний, а клипы для ролей выбраны анализом движения (имён в данных нет). Клипы с
  фиксированным форматом анимированных переносов/масштабов (38 из 4 444 в core_common, ни одного у Делсина) не
  декодируются. Float-каналы клипов не используются. Корневое движение не применяется (клипы локомоции на месте).
* **Лицо и ткань — приближения:** часть c1e00 (лицо) использует локальную палитру из 141 сустава, карта которой не
  найдена — лицо едет на суставе головы без мимики; глаза — жёсткие части на глазных суставах; 240 суставов ткани
  (413–652) копируют преобразование телесного сустава с наибольшим общим весом (в игре — вторичная симуляция).
* **Движение:** скорости ходьбы/бега взяты из клипов (опора стопы), прыжок и гравитация — прежние подобранные
  значения; паркура, рывка, системы навыков нет.
* **Коллизии:** оригинальные формы Havok (`hknpCompressedMeshShape`) дают скалы, стволы, постройки; грунта в них
  нет — грунт берётся из проходимых рендер-треугольников (приближение, отдельный слой). Выпуклые формы пропсов
  (`hknpConvexPolytopeShape`) и привязка коллизии пропсов к экземплярам не разобраны. Фильтры столкновений и
  материалы поверхностей Havok (data runs) не используются.
* **Мир:** несколько чанков грузятся при старте (по умолчанию a1, a5, a2); асинхронного стриминга и выгрузки нет;
  соседство задаётся списком в ini; виды экземпляров 2/4/6 не рисуются.
* **Варианты одежды** выбираются эвристикой (маска видов + дубликаты) и `HideParts`.
* **Материалы:** только цветовая карта; нормали, маски, шейдеры игры, освещение, тени — нет. Освещение — заглушка.
* **Нет звука, меню, сохранений, NPC, способностей** (способность дыма не начата).
* Тесты на реальных данных требуют `E:\shdps4\CUSA00004` (или `SSPC_GAME_DIR`), иначе SKIP.
* Проверено на RTX 2060 / NVIDIA этой машины; на других GPU не проверялось.

## N12 (миссии и граффити)

* **Логика миссий — нативная реконструкция:** VM скриптов splice не декодирована; `config/missions/vor_prologue.mission`
  задаёт переходы по оригинальным текстам/объектам. Катсцены не воспроизводятся (сообщение «not reconstructed»).
* **Здание консервного завода и щит не рисуются** (модели `OBJECT_DATA` чанка `a8` не разобраны): мостик и подложка —
  серые приближения; оригинальные объёмы «спустился с крыши» недостижимы, добавлен резервный объём.
* Начало системы объектов чанка `a8` выведено по камере граффити; общее правило для чанков не доказано.
* Граффити: композиция слоёв, кисть, правило завершения стадии, курсор и переходы камеры — нативные; анимации
  рисования и встряхивания нет; FOV и `PAINT_SIZE` по умолчанию из eboot не найдены.
* Масштаб `VOLUME_BUTTON` трактуется как полуразмеры в метрах (единичная фигура не разобрана).
* Сохранения — нативный формат (`SSPCSAVE`), не PS4.
* Геймпад в мини-игре проверен тестами, живой прогон с контроллером не выполнялся.
