# Известные ограничения (честный список)

* **Нет оригинальной анимации.** Скелет (653 сустава) и скиннинг работают, но клипы игры не найдены; поза и
  ходьба — процедурный тест (`TestPose`, `[Character] TestAnimation`), не восстановленное поведение. Одна часть
  головы (c1e00) использует другую кодировку весов и остаётся жёсткой.
* **Движение персонажа — техническая заглушка:** параметры (скорость, прыжок, гравитация) подобраны, а не взяты
  из игры; паркура, рывка, системы навыков нет.
* **Коллизии — не игровые:** опора — проходимые треугольники рендер-геометрии (`TerrainGrid`), стен нет; данные
  Havok (`hkcd*`) не разобраны.
* **Варианты одежды** выбираются эвристикой (маска видов + удаление дубликатов) и `HideParts` в ini; механизм игры
  (флаги экземпляра, таблица `0xad0`) не восстановлен. Маска с ушами (c0700) скрыта вручную.
* **KNLX разрешаются только для слотов геометрии** (a1: 33/33, через таблицы экспорта `core_village`/`core_common`
  из `[World] TexturePackages`); 296 ссылок a1 на негеометрические объекты не используются; у героя 2 цветовые
  карты не найдены ни в одном из подключённых пакетов. Набор общих пакетов задаётся в ini вручную.
* **Материалы:** используется только цветовая карта (категория 1); нормали, маски, шейдеры игры, освещение,
  тени — нет. Освещение — заглушка (солнце + полусфера). sRGB для цветовых карт — гипотеза.
* **Рельеф/скалы** без текстур (многослойные материалы не разобраны).
* **Мир:** загружается один чанк; стриминга, LOD, отсечения по видимости нет (вид 2/4/6 экземпляров не рисуется).
* **Нет звука, меню, сохранений.**
* Тесты на реальных данных требуют `E:\shdps4\CUSA00004` (или `SSPC_GAME_DIR`), иначе SKIP.
* Валидация показывает 0 сообщений на RTX 2060 / драйвере NVIDIA этой машины; на других GPU не проверено.
