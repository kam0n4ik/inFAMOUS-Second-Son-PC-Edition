# Архитектура нативного рантайма (native/)

## Граница

`native/` — отдельная программа. Она не включает и не линкует ничего из `src/` (гибридный порт),
`third_party/shadPS4`, PS4 SDK. Это проверяется при каждой конфигурации (`cmake/boundary_check.cmake`) и после
сборки (`sspc_depaudit`: импорты PE, строки, реально загруженные DLL). Обмен с эталоном — только знаниями
(документы, адреса eboot для исследования) и игровыми данными пользователя.

```
SecondSonPC.exe (game/main.cpp)
  ├─ platform/   Win32 окно, raw-мышь, клавиатура, XInput (LoadLibrary), действия с переназначением
  ├─ core/       лог, крэш-хендлер (minidump), INI-конфиг, файлы (mmap, атомарная запись), часы QPC, задачи, CRC-32, математика
  ├─ resources/  KCAP-пакеты → геометрия, текстуры, сцены чанков; библиотека текстур по id; .spcmesh
  ├─ renderer/   Vulkan 1.3: своя таблица функций, swapchain, глубина, BC-текстуры, кэш конвейеров, таймстемпы, скриншоты
  ├─ scene/      модель персонажа (части, варианты, цветовые карты), сцена чанка мира, камеры, примитивы
  └─ gameplay/   фиксированный шаг симуляции, кинематика персонажа, сетка проходимых поверхностей
tools/: sspc_inspect, sspc_convert, sspc_depaudit; research/*.py (исследование форматов)
tests/: sspc_tests (юнит + реальные данные), CTest
```

## Поток данных

```
art/cache/*.xpps ──KcapFile (mmap, проверка таблиц, KNLI)──► GeometryRecord / ChunkScene / TextureInfo
   ──DecodeGeometry / DecodeTexture (job system)──► MeshData (метры) / TextureData (линейные BC-блоки)
   ──Renderer::UploadMesh / UploadTexture──► GPU
игровой цикл: ввод → N фиксированных шагов (StepCharacter, TerrainGrid) → камера → DrawItem[] → RenderFrame
```

Командных буферов PS4, PM4, Gnm, трансляции шейдеров GCN нет: рендерер принимает только меши, текстуры и
матрицы движка; шейдеры собственные (GLSL → SPIR-V при сборке).

## Ключевые решения

| Решение | Почему |
|---|---|
| Vulkan 1.3 (dynamic rendering, sync2) | SDK и драйвер есть, опыт проекта, валидация; один API |
| vulkan-1.dll через LoadLibrary | exe запускается без драйвера и сообщает ошибку; нет импорта |
| MSVC cl + Windows SDK, без сторонних библиотек | ТЗ: MSVC при наличии; никакого кода из дерева shadPS4 |
| BC-текстуры без перекодирования | формат игры = формат GPU ПК; нужен только детайлинг thin-1D |
| Метры, Z вверх, начало модели у ступней | игра — сантиметры, Z вверх (подтверждено) |
| Фиксированный шаг 60 Гц + интерполяция | физика не зависит от FPS (тест на 30/60/144/240) |
| Структурная валидация вместо типов рефлексии | 7 084 типа без имён; поля проверяются по ссылкам KNLI |
