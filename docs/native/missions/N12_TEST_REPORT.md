Машина: RTX 2060, Ryzen 5 5500, Windows 10, 1600×900. Рабочая копия `E:\SecondSonPC-missions`, ветка
`feature/native-missions` (от `806ec6f`). Сборка `native\build.ps1` (MSVC 14.44, Vulkan SDK из `E:\VulkanSDK`).

| Конфигурация | Результат |

Новые тесты (24):

* **Mission Runtime** (`tests/test_mission.cpp`, без игровых данных; определения помечены как тестовые):
  разбор и проверка определения; 17 видов некорректных определений + двоичный мусор; запуск, последовательные цели,
  ожидания в последовательностях, условия-конъюнкции, одноразовый и повторяемый (по таймеру) триггеры,
  повторное событие завершённой цели (без второй награды); отмена последовательности при завершении цели;
  приостановка с буферизацией событий; провал и повтор цели; сохранение/загрузка посреди ожидания (действие не
  повторяется, награда не удваивается, одноразовый триггер остаётся сработавшим); усечённое/подменённое состояние
  отвергается без изменений; контейнер сохранения: порча каждого 5-го байта, неверная версия, усечение; шина событий:
  порядок и ограничение обратной связи.
* **Граффити** (`tests/test_graffiti.cpp`, синтетическая стена): маркеры → UV; вход (переход камеры), рисование,
  проявление, вторая стадия, завершение (ровно одно событие, камера вернулась), повтор после завершения невозможен;
  прерывание с сохранением краски и продолжение; мышь и стик (одинаковые метры по осям, ограничение стеной),
  распыление через ввод; сохранение масок (RLE), загрузка, завершение после загрузки, порча данных; сохранение в
  окне финального выхода (до события завершения) → после загрузки ровно одно `GraffitiCompleted` (найдено ревью
  кода: раньше мини-игра становилась незавершаемой).
* **Оригинальные данные** (`tests/test_n12_assets.cpp`, пропускаются без игры): хеш имён и реестр типов; `msn_vor`
  (1 232 объекта, 24 цели, 10 точек героя, 58 объёмов, тексты брифингов); все 65 пакетов миссий — вид 0xA и один
  `MISSION_DATA`; определение `graffiti_a8_family` (точные размеры, камера, стадии, цвета, 14 + 11 маркеров);
  **все 59 пакетов граффити** разбираются; прокси-сайт и вывод начала системы чанка по камере (центр по Y ±2 см,
  по высоте ±6 см, расстояние 4–6 м; точка героя на нижней кромке щита ±3 см); тексты (включая реплики с
  заголовком); **сквозной безголовый прогон пролога** (вступление → граффити → «escape_roof» → резервный объём →
  «escape_cannery», XP 100 → 150); сохранение/загрузка посреди стадии 2 и порча файла.

Прежние 48 тестов N11 проходят без изменений.
