# Граффити (stencil art): исследование и нативная реализация (N12)

Метки как в `MISSION_FORMAT_RESEARCH.md`. Код: `resources/graffiti_data.*` (чтение), `gameplay/graffiti.*` (логика),
`gameplay/prologue.*` (подключение), `shaders/decal.frag`, `renderer/renderer.cpp` (декали, маски).

## 1. Где и что [П]

* Пакеты `graffiti_<чанк>_<имя>[_good|_evil].xpps`, вид 0x19, 59 штук (все 59 разбираются тестом
  `n12_every_graffiti_package_loads`). В деревне (чанки `a#`) единственный — **`graffiti_a8_family`** (без вариантов
  good/evil, т. е. сюжетный). Тексты UI: «Stencil Art» (`u_button_graffiti`, `u_title_graffiti`),
  «Begin Stencil Art» (`u_interact_begin_graffiti`), «Stencil Art Completed», в миссии VOR — `u_brief_vor_graffiti_prompt`
  «[R2]/[L2] Spray-paint».
* Мини-игру ставит в мир объект чанка `a8` типа `PROXY_SITE_DATA` с **тем же OID**, что у `GRAFFITI_MINIGAME_DATA`
  пакета (`0x4a399b4da8529383`): позиция (1119,9; −141,2; 2541,4) см в системе чанка, поворот 180° вокруг Z.
  Там же `GRAFFITI_PROXY_SITE_DATA` ссылается на файл `graffiti_a8_family.xpp`, `USE_BUTTON_DATA` (радиус 200 см)
  — с подсказкой `u_button_graffiti`.
* Граффити относится к миссии **VOR** (реплики `m_vor_graffiti_*`, `m_vor_tagreg_*`, «tag it»): это карикатура на
  шерифа (руки с пончиком и пистолетом, усы, зубы) — Реджи, брат Делсина, отсюда «family».

## 2. Данные мини-игры [П]

Свойства задаёт код splice объекта; значения прочитаны из операндов (§5 MISSION_FORMAT_RESEARCH):

| Свойство (поле `CGraffitiMinigame`) | graffiti_a8_family |
|---|---|
| `PHYS_DIMENSIONS` (+0x4f0) | (7,2; 691,3; 360,8) см — толщина, ширина, высота: щит 6,9 × 3,6 м |
| `CAMERA_POS` (+0x4c0) | (10 636,7; −20 132,5; 2 536,9) см, **мировые** |
| `CAMERA_EULER` (+0x4d0) | (0; −0,1214; −0,0159) рад |
| `CAMERA_FIELD_OF_VIEW` (+0x4e0), `PAINT_SIZE` (+0x508) | не заданы (значения по умолчанию в eboot не найдены) |
| `GEOM_NOPAINT` (+0x500) | геометрия `0x6d113b57d733` (прямоугольник с прозрачной текстурой 1×1 (0,0,0,0)) |
| `ADD_STAGE` ×2 | см. ниже |

`ADD_STAGE(трафарет, краска, проявление, цвет, цвет подсветки, маркеры)`: аргументы в коде — блок
`{u64, u64, u64, pad, vec4, vec4}`; в рантайме стадия 0x50 байт в массиве `+0x4a8`, число `+0x4b0`
(`0x1ee960`, геттеры `0x1eeb00…0x1eec10`) [A].

| Стадия | Трафарет | Краска | Проявление | Цвет | Подсветка | Маркеры |
|---|---|---|---|---|---|---|
| 1 | `0x1174b60cb3b8459a` | `0x6d113b57d734` | `0xf6737289d61e08d6` | (1, 1, 1) белый | (1, 1, 1) | 14 |
| 2 | `0x1174b60cb3b8459b` | `0x6d113b57d735` | нет (~0) | (0, 0, 0) чёрный | (0,05; 0; 0,1) | 11 |

* Все id — первые 8 байт id геометрий пакета: шесть прямоугольников ±346,3 × ±180,4 см (совпадает с
  `PHYS_DIMENSIONS`); трафареты на 3 см перед стеной, слои краски — на её плоскости. UV: u = (y + 346,3)/692,6,
  v = (z + 180,4)/360,8; текстуры хранятся снизу вверх (надписи «SALMON BAY CANNERY» на картоне в прямой выгрузке
  отражены по вертикали), поэтому прямое UV даёт правильное изображение (усы над ртом).
* Маркеры: аргумент «markers» не непосредственный; k-й `LO_ARRAY_DATA` пакета (+0x58 → массив OID, +0x60 число)
  перечисляет `TRANSFORM`-объекты k-й стадии. Все 14 маркеров стадии 1 лежат на белых формах маски стадии 1
  (при перевёрнутом V — только 5) → маркеры = точки-цели распыления.

## 3. Текстуры слоёв [П]

| Слой | Текстура | Содержимое |
|---|---|---|
| трафарет 1 | 2048×1024 BC3 | картон с карандашным наброском; альфа ≈36 (дыры) на белых формах, ≈229 вне |
| трафарет 2 | 1024×512 BC3 | картон с вырезами; альфа ≈83 на чёрных деталях, ≈228 вне |
| краска 1, проявление 1 | 1024×512 BC3 | RGB — белые формы стадии 1, альфа — «зерно» распыления |
| краска 2 | 2048×1024 BC3 | итоговое ч/б изображение; фон — нейтральный серый 128 с нулевой альфой |
| общие | BC5 нормали, 2 × BC4 | картон |

## 4. Механизм оригинала — что установлено

* **Не рисовалка по текстуре и не смена текстур:** слои-прямоугольники (картонный трафарет с вырезами поверх стены
  + слой краски стадии), краска проявляется по **накопленной маске распыления**: рендер в eboot делает compute-
  диспатч в буфер 0x8000 (`0x1ed990`) и строит диск распыления из 8 сегментов (sin(i·45°), `0x1edb60`); в строках
  eboot — проходы `SpraypaintMask`, `SpraypaintMaskShadow`, `FX_SPRAYPAINT`, `FX_COPY_TEXTURE_STENCIL` [A][П].
* Две стадии последовательно: белая краска через трафарет 1, затем чёрная через трафарет 2 [П].
* Камера мини-игры: `CAMERA_POS/EULER`; по данным она смотрит в центр щита: луч с рысканием −0,0159 (правило правой
  руки) попадает в центр по Y с точностью 1 см на расстоянии 4,83 м, по высоте камера на 4,5 см ниже центра [П].
* Делсин стоит на нижней кромке щита (`HERO_MATCH_POINT` миссии VOR, ±3 см) [П].
* Строка `SprayShake` (действие ввода) — встряхивание баллончика есть в игре [П: строка], механика не разобрана.

## 5. Нативная реализация — что из оригинала, что своё

| Часть | Источник |
|---|---|
| геометрия, текстуры, стадии, цвета, маркеры, размеры, камера, место установки | **оригинальные данные** |
| маска распыления 512×256 на стадию, мягкий диск, накопление | нативно (механизм — как в игре, параметры свои) |
| правило «стадия выполнена, когда покрыты все маркеры» | нативное правило на оригинальных маркерах |
| композиция слоёв в шейдере (режимы `TintedShape`/`Image`/`Board`) | приближение (шейдер игры не декодирован) |
| выбор режима слоя: есть геометрия проявления → тон цвета стадии × форма; нет → изображение слоя | приближение |
| проявление стадии (заливка маски за 0,6 с), трафарет полупрозрачен во время проявления | нативно |
| курсор (мышь/стик), лёгкое следование камеры за курсором (±0,06 рад), переходы камеры 0,9/0,8 с, FOV 60° | нативно |
| индикаторы маркеров (жёлтые → зелёные), круг распыления | нативный UI |
| анимация Делсина при рисовании | **нет** (клипы распыления среди 2 034 клипов не опознаны; используется idle) |
| встряхивание баллончика, расход краски | нет |

Управление: подход к щиту — подсказка `[E / X] Stencil Art`; мышь/стик — курсор; ЛКМ/F/RT — распыление;
Q/Backspace/B — выйти (прогресс сохраняется, повторное взаимодействие продолжает ту же стадию).

## 6. Связь с миссией

Мини-игра публикует события `GraffitiStarted`, `GraffitiStageCompleted(стадия)`, `GraffitiAborted`,
`GraffitiCompleted(OID)`; цель `tag_billboard` миссии `vor_prologue` выполняется по
`event GraffitiCompleted 0x4a399b4da8529383`, после чего выдаётся следующая цель (оригинальный текст
«Find a safe way down off the fish cannery roof»). Прогресс (маски, стадия, флаг завершения) сохраняется.

## 7. Чего не хватает до полного восстановления

1. Шейдер краски игры (точная композиция, зерно, подтёки), параметры кисти (`PAINT_SIZE` по умолчанию), правило
   завершения стадии в оригинале.
2. Анимации Делсина (распыление, встряхивание) и камера оригинала при рисовании (следование, тряска).
3. Здание консервного завода и сам щит (модели `OBJECT_DATA` `a8`) — сейчас серые приближения в коде.
4. Катсцены `vor_taggin` (до) и `vor_spotlight` (после) не воспроизводятся.
