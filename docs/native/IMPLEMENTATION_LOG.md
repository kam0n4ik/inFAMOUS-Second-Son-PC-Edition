* **Сделано:** `engine/core/*`, `engine/platform/*`, `engine/resources/{kcap,gcn_buffer,geometry,spcmesh}`,
  `engine/renderer/{vk_api,renderer}`, `engine/gameplay/{game_loop,character}`, `engine/scene/*`, `game/main.cpp`,

  совпадают с гранями 0,976, обход CCW 100 %); запуск с валидацией Vulkan — 0 сообщений; скриншот.
* **Осталось:** текстуры, мир, анимация.
