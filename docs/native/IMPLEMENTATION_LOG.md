# Журнал реализации (native/)

## 2026-10-15 — N1–N3: рантайм, KCAP, геометрия, рендерер (коммит 22de3da)
* **Сделано:** `engine/core/*`, `engine/platform/*`, `engine/resources/{kcap,gcn_buffer,geometry,spcmesh}`,
  `engine/renderer/{vk_api,renderer}`, `engine/gameplay/{game_loop,character}`, `engine/scene/*`, `game/main.cpp`,
  `tools/{asset_inspector,asset_converter,dep_audit}`, `tests/*`, `CMakeLists.txt`, `build.ps1`.
* **Как работает:** KCAP мапится в память, таблицы проверяются по размеру файла, KNLI декодируется как в eboot
  (`0x5d2260`); записи геометрии ищутся по ссылкам (+0x60 → V#), потоки декодируются в float.
* **Проверено:** 25 тестов (повреждённые пакеты, 3000 случайных искажений, реальный hero.xpps: 41 часть, нормали
  совпадают с гранями 0,976, обход CCW 100 %); запуск с валидацией Vulkan — 0 сообщений; скриншот.
* **Осталось:** текстуры, мир, анимация.
