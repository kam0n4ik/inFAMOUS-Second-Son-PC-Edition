## 2. Новая архитектура (что реально создано)
Отдельная программа `native/` (C++20, MSVC 14.44, CMake/Ninja), не включающая и не линкующая ничего из `src/`,
`third_party/shadPS4`, PS4 SDK (проверка CMake на каждую конфигурацию). Слои — `docs/native/ARCHITECTURE.md`.

скелете) на тестовой площадке или на рельефе оригинального чанка мира `a1.xpps` (1 492 экземпляра, 205 мешей,
36 текстур, хвоя с альфа-тестом). Освещение — заглушка. Валидация Vulkan — 0 сообщений; GPU ≈1,5 мс/кадр (RTX 2060).

## 7. Игровая логика
Работает: фиксированный шаг (детерминирован на 30/60/144/240 Гц), ходьба/бег/прыжок/приземление, опора на
проходимые треугольники оригинального рельефа, возврат на точку при падении, камера от третьего лица и свободная.
Это **техническая** логика: параметры движения и поза-ходьба процедурные, не восстановлены из игры.

## 10. Демонстрация
```
cd E:\SecondSonPC-rebirth\native\build\release\bin
SecondSonPC.exe --config E:\SecondSonPC-rebirth\native\config\SecondSonPC.ini --chunk art\cache\a1.xpps
```
WASD — движение, Shift — бег, Space — прыжок, мышь — камера (F2 — захват), F3 — свободная камера, `[` `]` —
выбор части, H — скрыть/показать часть, Esc — выход. Автопрогон: `--frames 300 --autoplay --validation
--screenshot x.bmp --modules m.txt`, затем `sspc_depaudit SecondSonPC.exe --modules m.txt`.
