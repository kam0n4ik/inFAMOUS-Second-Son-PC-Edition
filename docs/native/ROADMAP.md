# Дорожная карта (по проверяемым результатам)

| Этап | Статус | Критерий готовности |
|---|---|---|
| N0 аудит | готово | `N0_DEPENDENCY_AUDIT.md` |
| N1 Windows-рантайм | готово | exe без PS4/shadPS4 (аудит PE + загруженные DLL) |
| N2 форматы | частично | KCAP 1621/1621, геометрия, текстуры, сцены чанков — да; KNLX, анимации, коллизии, звук — нет |
| N3 рендерер | частично | меши, BC-текстуры, глубина, альфа-тест, валидация 0; материалы игры, тени, пост — нет |
| N4 движок | начато | фиксированный шаг, сцена; сущности/события игры — нет |
| N5 персонаж | начато | модель + текстуры + кинематика; скелет/анимации — **следующий шаг** |
| N6–N9 | не начато | способности, ИИ, звук, сохранения |
| N10 независимость | готово для текущей сборки | `sspc_depaudit` PASS |

Ближайшие три задачи:
1. **Скелет и анимации Делсина**: найти скелет (кости, иерархия, bind-pose) и клипы в `hero.xpps`/пакетах
   анимаций (в eboot есть Havok `hka*` и свой `CsMesh: Skin`); скиннинг на GPU по уже декодированным индексам/весам.
2. **KNLX**: разрешить внешние ссылки между пакетами (геометрия и текстуры из соседних чанков и общих пакетов) —
   даст полный чанк мира и одежду героя целиком.
3. **Коллизии игры**: разобрать Havok-формы чанка (`hkcdStaticMeshTree`) для стен и правильной опоры.
