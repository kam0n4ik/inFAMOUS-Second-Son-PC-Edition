## 3. Найдены ли оригинальные анимации — да
Клипы — блобы `'70AE'` (номер версии 7) в блоках типа 0. Формат восстановлен по коду eboot (только чтение в
Ghidra): сэмплер `0x71d50`, декодер клипа `0x887e60`, декодеры дорожек `0x88a070`/`0x88a520` (48-битные кватернионы
«smallest three»), `0x88c250` (константные переносы), `0x88f200`/`0x88fd70`/`0x891fe0`/`0x892a80` (переменная
разрядность: слово формата на дорожку, мини-float с порогом экспоненты 128−2^(e−1), big-endian битовый поток),
интерполяция slerp/lerp между ключами по битовым маскам сегментов.

Доказательства на данных:
* 255 константных переносов клипа Делсина = поза покоя с точностью 0,014 см;
* 4 406 из 4 444 клипов core_common декодируются, **все 2 034 клипа Делсина**, 0 невалидных значений;
* циклы ходьбы/бега/idle замыкаются (0,02°), углы колена анатомичны (ходьба 15–78°, бег 10–118°);
* визуально — естественные позы (`n11/clips_front.png`).

Клипы адресуют суставы скелета по индексу: у Делсина 653 сустава, из них анимационный риг — первые 413 (поле
+0x0E клипа = 413), суставы 413–652 — вспомогательные (ткань), их привязка в нуле.

## 4. Какие анимации реально воспроизводятся
Имён клипов в данных нет (только хеши) — роли определены анализом движения (FK по скелету: опора стоп, углы
колен, высота таза, замыкание цикла) и визуально:

| Роль | Клип (смещение в core_common) | Длина | Признаки |
|---|---|---|---|
| Idle | `0x1aed3a0` | 433 кадра, 14,4 с | стопы неподвижны (<0,5 мм), голова ±0,5 см |
| Walk | `0x26762a0` | 33 кадра | стопа в опоре 0,86 м/с вперёд, колено 15–78° |
| Run | `0x2777220` | 21 кадр | 4,9 м/с, колено до 118° |
| JumpStart | `0x3395ef0` | 8 кадров | таз 93→117 см, ноги поджимаются |
| Fall | `0x26f08f0` | 32 кадра, цикл | обе стопы в воздухе |
| Land | `0x316afe0` | 7 кадров | стопы 30→8 см, таз 99→81 см |

Нативная машина состояний (`scene/animator.*`): Idle ↔ Walk ↔ Run по скорости (пороги между скоростями клипов),
Grounded → JumpStart → Fall → Land → локомоция, плавные переходы 0,2 с (slerp/lerp поз), темп ходьбы/бега =
скорость / скорость клипа (стопы не скользят). Скорости персонажа берутся из клипов (0,86 и 4,9 м/с), а не
подбираются. Просмотрщик клипов: `--anim-clip <hex> --anim-phase <0..1> --camera-yaw <град>`.

**Не оригинальное:** сама машина состояний и её пороги (граф анимаций игры `ANIMATION_RUN`/`STRAFE_LAUNCH`/
`STRAFE_LANDING` не восстановлен); выбор конкретных клипов — по анализу, а не по данным игры.

## 5. Коллизии
* Персонаж — кинематическая капсула (`gameplay/character.cpp`): тело-капсула от высоты ступеньки до головы
  выталкивается из стен/потолков со скольжением вдоль поверхности, опора — 5 лучей вниз в пятне 0,7 радиуса,
  ограничение уклона (~50°), подъём/спуск ступенек до 0,35 м, подшаги ≤ половины радиуса против туннелирования,
  приземление. Пространственное ускорение — BVH по треугольникам (`gameplay/collision.*`), полного перебора нет.
* Фильтрация: слои треугольников (Havok / приближение) с маской в запросах.
* Отладочный вид коллизии: `F5` или `--show-collision`.

## 6. Используются ли оригинальные Havok-данные — да, частично
Все чанки деревни содержат Havok-packfile; в a1 — `hknpStaticCompoundShape` с 19 `hknpCompressedMeshShape`,
27 361 треугольник (скалы, стволы деревьев, постройки). **Поверхности грунта в этих формах нет** (доля
горизонтальных треугольников ≈0,3 во всех проверенных пакетах), поэтому грунт — проходимые треугольники
рендер-геометрии (явное приближение, отдельный слой). Пропсы (`hknpConvexPolytopeShape`) не разобраны.

## 7. Сколько чанков загружается
3 соседних чанка деревни (`a1` лес и скалы, `a5`/`a2` дома и причалы) в одной мировой системе координат —
совпадение подтверждено границами (коллизия a1 и рендер-экземпляры совпадают по всем осям) и визуально
(`n11/village.png`: Делсин стоит на досках причала из a5 рядом с рельефом a1). Общие пакеты открываются один раз,
меши общих пакетов и текстуры (по id) загружаются на GPU один раз (66 мешей переиспользованы). Перемещение между
чанками без перезапуска работает (коллизия объединена).
**Не сделано:** асинхронная подгрузка/выгрузка по расстоянию (стриминг) — чанки грузятся при старте.
