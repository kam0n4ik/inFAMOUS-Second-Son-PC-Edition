# Реверс-инжиниринг (только исследование; код игры не исполняется)

Инструменты: Ghidra headless (pyghidra, скрипты `E:\SecondSonPC\tools\native-reconstruction\ghidra`, копия проекта
`E:\tools\ghidra-projects\scripts`), исследовательские скрипты `native/tools/research/*.py`, визуальная проверка
декодированных мешей/текстур. Метки: [A] прочитано в коде eboot, [П] подтверждено на данных, [Г] гипотеза.

| Функция eboot | Что делает | Метка |
|---|---|---|
| `0x30a310` | обход служебного потока пакета (DIC/KNLI/KNLX/PYTO/PLPS/END) | [A][П] |
| `0x30a4a0` | ссылки KNLI, виды 0–4 | [A][П] |
| `0x5d2260` | декодер потока смещений KNLI | [A][П] (тест повторяет семантику, включая серию 0) |
| `0x5ee750` | перевод смещения в адрес через сегменты (+4 размер, +8 начало, +0x10 база) | [A] |
| `0x2a6e40` | бинарный поиск 64-битного хеша типа в таблице `0xa5ff70` (7 084 типа) | [A] |
| `0x30a700` / `0x30a910` / `0x30b1c0` | KNLX / PYTO / PLPS | [A], форматы не разобраны полностью |
| `0x4cfcb0` | поиск поля типа по хешу (таблица `0xd057a0`) — рефлексия | [A] |
| `0x30fc00` / `0x30fe30` | загрузчик пакета: блоки сегмента (+4 смещение, +10 тип), блок типа 6 → `+0x90` | [A][П] |
| `0x1a1960` | DrawSingle: геометрия +0x58 IB, +0x60 V#, +0x68 число индексов (из документов эталона) | [A][П] |
| `0x1ec170` | ModelInstance::SubmitToView: LOD по байтам `geom+0x18` и таблице `0xdfaa30`, части по 0x20 | [A] |
| `0x1d2540` | рендер одного объекта с матрицей `+0x160…+0x19c` (не массивы экземпляров чанка) | [A] |

| `0x71d50` | сэмплер клипа: кадр = (ключи − 1) × фаза, бинарный поиск сегмента, вызов декодера | [A][П] |
| `0x887e60` | декодер клипа: заголовок `'70AE'`, разделы сегмента, выбор декодеров по флагам +0x2C | [A][П] |
| `0x88a070` / `0x88a520` | константные / анимированные 48-битные кватернионы (slerp с полиномами) | [A][П] |
| `0x88c250` / `0x88ce40` | константные переносы (3 × f32, w = 1) / float-каналы | [A] |
| `0x88f200` / `0x88fd70` | вращения переменной разрядности (слово формата) | [A][П] |
| `0x891fe0` / `0x892a80` | переносы/масштабы переменной разрядности, lerp | [A][П] |

Найдено на данных (без кода): скелет `'60SE'`, Havok packfile и формы `hknp*` (раскладка полей измерена на
данных, проверена совпадением с позой покоя / границами рендера); деквантование позиций (+0x38/+0x44), объект сцены чанка, привязки текстур материала,
тайлинг 13 и раскладка mip-уровней — подробности и доказательства в `RESOURCE_FORMATS.md`.

Неопределённости: роли видов экземпляров 2/4/6; поля u16 `extra` экземпляра; категории 3/4 текстур; таблица
вариантов модели `0xad0`; форматы KNLX/PYTO/PLPS; где хранятся скелет и анимации.
